# 아임웹 견적서 위젯

아임웹 페이지에서 **평수만 넣으면 회사 견적서 양식이 그대로 채워지는** 위젯입니다.
직원용이라 접속 번호를 먼저 묻습니다. **PC와 휴대폰 모두 이 세 파일 하나로 됩니다.**

```
한번에붙여넣기.html   ← 아임웹 「HTML」 블록에 통째로 붙여넣는 한 파일 (쉬움)

widget.html   Widget Studio의 HTML 탭에 붙여넣기
widget.css    CSS 탭에 붙여넣기
widget.js     JS 탭에 붙여넣기
onefile.py    위 세 파일을 합쳐 `한번에붙여넣기.html`을 다시 만드는 스크립트
```

## 방법 1 — 한 번에 붙여넣기 (쉬움)

1. 아임웹 관리자 → 페이지 편집 → 위젯 추가 → **HTML**(코드 삽입) 블록
2. `한번에붙여넣기.html` 을 열어 **처음부터 끝까지 전부 복사**해 넣고 저장
3. 값을 바꿀 곳은 파일 안 `<section class="iw-quote" ...>` 줄뿐입니다
   - `data-pin="8282"` — 접속 번호 (비우면 번호 없이 열립니다)
   - `data-form-url=""` — 웹 폼 주소를 넣으면 "웹 폼 열기" 링크가 보입니다
   - `data-roof-*` / `data-wall-*` — 평당 단가와 1식 금액 (숫자만)
4. 직원만 아는 페이지(숨긴 페이지)에 올립니다

설정 패널이 없는 대신 **도장 그림이 파일 안에 들어 있어** 따로 올릴 것이 없습니다.
단가를 바꾸려면 블록 코드를 직접 고칩니다. 한 페이지에 **하나만** 붙여넣으세요.

코드 에디터 창에 적힌 조건 두 가지를 먼저 확인하세요.

> **"Free 버전에서는 스크립트가 제거되고 저장돼요"** — 무료 요금제면 `<script>`가 지워져서
> 입력해도 계산이 안 됩니다. 이때는 같은 창 오른쪽 위 **커스텀 위젯 만들기**(Widget Studio)로
> 들어가 아래 방법 2로 하세요.
>
> **"주석은 제거되고 저장돼요"** — 파일 맨 위 설명(`<!-- ... -->`)은 저장하면 사라집니다.
> 기능에는 영향이 없지만, 나중에 고칠 때 보려면 `한번에붙여넣기.html` 원본을 따로 두세요.

창 아래 **글자 수**가 51,926자로 찍힙니다. 저장이 거부될 만큼 길다면 `<img class="iw-seal"`의
`src="data:image/png;base64,..."` 를 사이트에 올린 도장 그림 주소로 바꾸면 12,600자가 줄어듭니다.

## 방법 2 — Widget Studio 세 탭에 붙여넣기

> **이 위젯은 지금 Widget Studio에 들어가지 않습니다.** 아임웹은 위젯 하나의 코드를
> HTML·CSS·JS **각 탭 1만 자**까지만 받는데, 이 위젯은 HTML 10,909자 · CSS 13,818자 ·
> JS 15,580자입니다. 그래서 실제로 쓸 수 있는 길은 **방법 1(코드위젯)** 하나입니다.
> 무료 요금제라 코드위젯이 스크립트를 지운다면, 아임웹 대신 `notion-worklog`의 웹 폼을
> 쓰는 쪽이 현실적입니다(그쪽은 PDF 파일도 바로 내려옵니다).
> 아래 절차는 나중에 코드를 1만 자 아래로 줄였을 때를 위해 남겨 둡니다.

1. 아임웹 관리자 → 디자인 → **위젯 만들기**(Widget Studio) → 새 위젯
2. 세 파일의 내용을 각각 **HTML / CSS / JS 탭**에 그대로 붙여넣고 저장
3. 오른쪽 설정 패널에서 값을 채웁니다
   - **접속 번호** — 직원에게 알려줄 번호 (기본 `8282`). 비우면 번호 없이 열립니다
   - **대표자 도장** — `notion-worklog/assets/seal.png`를 올리면 견적서에 찍힙니다
   - **단가** — 옥상방수 8개, 외벽방수 5개. 기본값은 실제 견적서와 같습니다
   - **웹 폼 주소** — 맥에서 웹 폼을 켰다면 그 주소. 넣으면 "웹 폼 열기" 링크가 보입니다
4. 직원만 아는 페이지(숨긴 페이지)에 이 위젯을 올립니다

> 단가를 패널에서 고치면 **저장 후 페이지를 새로 고쳐야** 반영됩니다.
> (위젯 편집기 미리보기는 JS를 다시 실행하지 않습니다.)

## 쓰는 법

1. 접속 번호를 넣고 들어갑니다
2. 작업항목(옥상방수 / 외벽방수), 고객명, 평수를 넣습니다 → **견적서가 즉시 채워집니다**
3. 단가를 현장에서 바꾸려면 **요약 보기**에서 품목의 `단가` 칸을 눌러 고칩니다
   → 금액·합계·견적서가 즉시 따라옵니다. 빈칸으로 두면 그 품목은 견적서에서 빠집니다.
   **기본 단가로 되돌리기**를 누르면 설정값으로 돌아옵니다(고친 단가는 새로 고치면 사라집니다)
4. 네고 금액이 있으면 `최종 금액`에 넣고, `단가 조정`을 켜면
   하도·중도·상도 방수코트 단가를 **원래 비율(3 : 6 : 4)대로 다시 나눠** 합계를 그 금액에 맞춥니다
   (이때 방수코트 3개의 단가 칸은 자동 계산되므로 잠깁니다)
5. PDF가 필요하면 키보드 **Command + P**(윈도우 `Ctrl + P`) → **PDF로 저장**

## 휴대폰에서

위젯이 놓인 **칸의 너비가 620px보다 좁아지면** 자동으로 모바일 배치로 바뀝니다.
아임웹 모바일 편집 화면은 화면 크기가 아니라 칸만 좁아지므로, 화면 크기(미디어쿼리)가
아니라 칸의 너비를 재서 판단합니다. 그래서 PC용·모바일용 위젯을 따로 만들 필요가 없습니다.

바뀌는 것:

- 입력칸이 **한 줄에 하나씩** 세로로 놓이고, 높이 48px·글자 16px이 됩니다
  (16px보다 작으면 아이폰이 입력할 때 화면을 확대해 버립니다)
- 견적서 위에 **「요약 보기 / 견적서 양식」** 버튼이 생깁니다(PC에서도 보입니다)
  - **요약 보기** — 표 대신 품목을 카드로 세워 보여 주고, **단가를 눌러 고칠 수 있습니다.**
    확대하지 않고 읽을 수 있습니다. 휴대폰에서는 이 화면이 기본입니다
  - **견적서 양식** — 종이 양식(가로 190mm) 그대로, 칸 너비에 맞게 통째로 축소해서 보여 줍니다.
    PC에서는 이 화면이 기본입니다
- 아이폰 사파리가 표 안 글씨를 제멋대로 키워 칸을 넘치게 하는 것을 막아 두었습니다
  (`text-size-adjust: 100%`). 단가 칸은 16px로 두어 누를 때 화면이 확대되지 않습니다
- 아이폰 SE처럼 폭이 360px보다 좁으면 글자를 한 단계 더 줄입니다
- 안내문이 휴대폰용 PDF 저장 방법으로 바뀝니다

**인쇄·PDF는 어느 보기 상태에서든 언제나 A4 양식 그대로** 나갑니다(요약 카드는 인쇄되지 않습니다).

휴대폰에서 PDF로 남기는 방법:

- 아이폰 사파리 — 아래 **공유** 버튼 → **프린트** → 미리보기를 두 손가락으로 확대 →
  다시 **공유** → **파일에 저장**
- 안드로이드 크롬 — 오른쪽 위 **메뉴** → **공유** → **인쇄** → **PDF로 저장**

## 알아 둘 점

- **위젯이 PDF 파일을 직접 만들어 주지는 못합니다.** 아임웹 위젯 샌드박스가
  파일 내려받기·인쇄 실행·외부 통신을 모두 막기 때문입니다. 그래서 화면에 견적서를
  그려 주고 브라우저 인쇄로 PDF를 저장하는 방식입니다.
- 인쇄하면 **아임웹 사이트의 머리말·꼬리말이 함께 나올 수 있습니다.** 위젯 안에서는
  사이트의 다른 부분을 숨길 수 없습니다. 깔끔한 PDF 파일이 필요하면
  `notion-worklog`의 웹 폼(`/quote` 화면)을 쓰세요 — 그쪽은 파일이 바로 내려옵니다.
  휴대폰에서 PDF 파일을 바로 받아야 할 때도 웹 폼이 편합니다.
- 금액 계산 규칙은 `notion-worklog/quote.py`와 같습니다(평당 단가, 3:6:4 비율,
  금액 1,000원 단위·단가 10원 단위). **기본** 단가를 바꾸려면 양쪽 모두 고쳐 주세요
  (`quote_config.json` ↔ `한번에붙여넣기.html`의 `data-roof-*`·`data-wall-*`).
  요약 보기에서 고친 단가는 그 화면에서만 쓰이고 저장되지 않습니다.
- 회사 정보(상호·등록번호·주소)는 `widget.js` 위쪽 `BRANDS`에 있습니다.
  옥상방수는 청명옥상방수, 외벽방수는 청명종합설비로 나갑니다.

## 미리 확인하기

아임웹에 올리기 전에 브라우저로 확인하려면:

```bash
python3 preview.py    # widget-preview.html 을 만들고 브라우저로 열면 됩니다
python3 onefile.py    # 세 파일을 고친 뒤 한번에붙여넣기.html 을 다시 만들 때
```

`한번에붙여넣기.html`은 그 자체로 브라우저에서 바로 열려 보입니다.

휴대폰 화면은 브라우저 창을 좁게 줄이거나, 크롬 개발자도구의 기기 모드(390px)로 보면 됩니다.
`견적서위젯-모바일-예시.html`은 **자바스크립트 없이** 열리는 모바일 화면 예시입니다
(버튼은 눌리지 않고, 화면 모양만 보는 용도).
