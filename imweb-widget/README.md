# 아임웹 견적서 위젯

아임웹 페이지에서 **평수만 넣으면 회사 견적서 양식이 그대로 채워지는** 위젯입니다.
직원용이라 접속 번호를 먼저 묻습니다. **PC와 휴대폰 모두 이 세 파일 하나로 됩니다.**

```
widget.html   Widget Studio의 HTML 탭에 붙여넣기
widget.css    CSS 탭에 붙여넣기
widget.js     JS 탭에 붙여넣기
```

## 붙여넣는 순서

1. 아임웹 관리자 → 디자인 → **위젯 만들기**(Widget Studio) → 새 위젯
2. 세 파일의 내용을 각각 **HTML / CSS / JS 탭**에 그대로 붙여넣고 저장
3. 오른쪽 설정 패널에서 값을 채웁니다
   - **접속 번호** — 직원에게 알려줄 번호 (기본 `8282`). 비우면 번호 없이 열립니다
   - **대표자 도장** — `notion-worklog/assets/seal.png`를 올리면 견적서에 찍힙니다
   - **단가** — 옥상방수 8개, 외벽방수 5개. 기본값은 실제 견적서와 같습니다
   - **웹 폼 주소** — 맥에서 웹 폼을 켰다면 그 주소. 넣으면 "웹 폼 열기" 링크가 보입니다
4. 직원만 아는 페이지(숨긴 페이지)에 이 위젯을 올립니다

> 단가를 패널에서 고치면 **저장 후 페이지를 새로 고쳐야** 반영됩니다.
> (위젯 편집기 미리보기는 JS를 다시 실행하지 않습니다.)

## 쓰는 법

1. 접속 번호를 넣고 들어갑니다
2. 작업항목(옥상방수 / 외벽방수), 고객명, 평수를 넣습니다 → **견적서가 즉시 채워집니다**
3. 네고 금액이 있으면 `최종 금액`에 넣고, `단가 조정`을 켜면
   하도·중도·상도 방수코트 단가를 **원래 비율(3 : 6 : 4)대로 다시 나눠** 합계를 그 금액에 맞춥니다
4. PDF가 필요하면 키보드 **Command + P**(윈도우 `Ctrl + P`) → **PDF로 저장**

## 휴대폰에서

위젯이 놓인 **칸의 너비가 620px보다 좁아지면** 자동으로 모바일 배치로 바뀝니다.
아임웹 모바일 편집 화면은 화면 크기가 아니라 칸만 좁아지므로, 화면 크기(미디어쿼리)가
아니라 칸의 너비를 재서 판단합니다. 그래서 PC용·모바일용 위젯을 따로 만들 필요가 없습니다.

바뀌는 것:

- 입력칸이 **한 줄에 하나씩** 세로로 놓이고, 높이 48px·글자 16px이 됩니다
  (16px보다 작으면 아이폰이 입력할 때 화면을 확대해 버립니다)
- 견적서 위에 **「요약 보기 / 견적서 양식」** 버튼이 생깁니다
  - **요약 보기**(기본) — 표 대신 품목을 카드로 세워 보여 줍니다. 확대하지 않고 읽을 수 있습니다
  - **견적서 양식** — 종이 양식(가로 190mm) 그대로, 칸 너비에 맞게 통째로 축소해서 보여 줍니다
- 안내문이 휴대폰용 PDF 저장 방법으로 바뀝니다

**인쇄·PDF는 어느 보기 상태에서든 언제나 A4 양식 그대로** 나갑니다(요약 카드는 인쇄되지 않습니다).

휴대폰에서 PDF로 남기는 방법:

- 아이폰 사파리 — 아래 **공유** 버튼 → **프린트** → 미리보기를 두 손가락으로 확대 →
  다시 **공유** → **파일에 저장**
- 안드로이드 크롬 — 오른쪽 위 **메뉴** → **공유** → **인쇄** → **PDF로 저장**

## 알아 둘 점

- **위젯이 PDF 파일을 직접 만들어 주지는 못합니다.** 아임웹 위젯 샌드박스가
  파일 내려받기·인쇄 실행·외부 통신을 모두 막기 때문입니다. 그래서 화면에 견적서를
  그려 주고 브라우저 인쇄로 PDF를 저장하는 방식입니다.
- 인쇄하면 **아임웹 사이트의 머리말·꼬리말이 함께 나올 수 있습니다.** 위젯 안에서는
  사이트의 다른 부분을 숨길 수 없습니다. 깔끔한 PDF 파일이 필요하면
  `notion-worklog`의 웹 폼(`/quote` 화면)을 쓰세요 — 그쪽은 파일이 바로 내려옵니다.
  휴대폰에서 PDF 파일을 바로 받아야 할 때도 웹 폼이 편합니다.
- 금액 계산 규칙은 `notion-worklog/quote.py`와 같습니다(평당 단가, 3:6:4 비율,
  금액 1,000원 단위·단가 10원 단위). 한쪽 단가를 고치면 **양쪽 모두** 고쳐 주세요.
- 회사 정보(상호·등록번호·주소)는 `widget.js` 위쪽 `BRANDS`에 있습니다.
  옥상방수는 청명옥상방수, 외벽방수는 청명종합설비로 나갑니다.

## 미리 확인하기

아임웹에 올리기 전에 브라우저로 확인하려면:

```bash
python3 preview.py    # widget-preview.html 을 만들고 브라우저로 열면 됩니다
```

휴대폰 화면은 브라우저 창을 좁게 줄이거나, 크롬 개발자도구의 기기 모드(390px)로 보면 됩니다.
`견적서위젯-모바일-예시.html`은 **자바스크립트 없이** 열리는 모바일 화면 예시입니다
(버튼은 눌리지 않고, 화면 모양만 보는 용도).
