# 수학을 잘하고 싶다면, 태도부터

## 다듬은 원고 (읽는 글 버전)

수학을 잘하고 싶다면, 문제집보다 태도부터 바꿔 보세요.

여기 두 장의 학습지가 있습니다.
한 장은 성적이 오른 아이의 것, 다른 한 장은 1년째 제자리인 아이의 것입니다.

두 아이는 비슷한 수준에서 출발했습니다.
같은 양을 풀었고, 같은 수업을 들었습니다.
그런데 1년이 지난 지금은, 수준 차이 때문에 반을 나눠 수업합니다.

사람들은 이걸 '수학 머리'라고 부릅니다.
저는 태도라고 부릅니다.

한 아이는 방향을 코칭해 주면, 잘 안 되더라도 일단 시도해 봅니다.

다른 아이는 시도조차 하지 않습니다.
"에이, 나만 못해." 그 말만 반복합니다.
문제를 같이 읽어 보자고 해도 읽지 않고, "못 풀어요"만 되풀이합니다.
푸는 게 아니라 글씨만 소리 내어 읽어 보자고 해도, 그것마저 거부합니다.

미안하지만, 결과는 뻔합니다.

실력의 차이는 머리에서 시작되지 않습니다.
"해볼게요"와 "못 해요".
그 한마디에서 갈립니다.

## 원문에서 손본 부분

| 원문 | 수정 | 이유 |
| --- | --- | --- |
| 같은양 | 같은 양 | 띄어쓰기 |
| 학습 빙향 | 학습 방향 | 오타 |
| 코칭하면 인되더라도 | 코칭해 주면 잘 안 되더라도 | 오타 + 문장 연결 |
| 에잉~ 나만 못해 | "에이, 나만 못해." | 대사 표기 정리 |
| 빈복 / 반복 | 반복 · 되풀이 | 오타 + 반복어 변주 |
| 글씨민 | 글씨만 | 오타 |
| 결괴는 뻔하죠? | 결과는 뻔합니다. | 오타 + 단정형으로 마무리 |
| — | 마지막 3줄 추가 | 릴스는 '한 문장 결론'이 있어야 저장·공유가 붙음 |

문장 길이를 자막 단위(한 줄 12~16자)로 끊었고, 나열식이던 뒷부분을
"한 아이 / 다른 아이" 대비 구조로 바꿔 대조가 눈에 들어오게 했습니다.
