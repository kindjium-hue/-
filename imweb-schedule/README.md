# 청명 일정 달력 (아임웹)

아임웹 **게시판에 일정 글을 올리면 달력에 자동으로 나타나는** 위젯입니다.
월간·주간으로 볼 수 있고, 날짜를 누르면 그날 일정이 펼쳐집니다. 직원용이라 접속 번호를 먼저 묻습니다.

```
아임웹-일정달력-복사용.txt   ← 코드 에디터에 통째로 붙여넣는 파일 (이것만 쓰면 됩니다)
한번에붙여넣기.html          내용 같음 (브라우저로 열면 바로 확인 가능)

widget.html / widget.css / widget.js   원본 세 파일
onefile.py   세 파일을 합쳐 위 두 파일을 다시 만드는 스크립트
preview.py   브라우저 확인용 한 장 HTML 만들기
```

> **Widget Studio(커스텀 위젯)에는 넣을 수 없습니다.** 이 위젯은 게시판 목록을 읽어야 해서
> `fetch`를 쓰는데, Widget Studio 샌드박스는 통신을 막고 탭당 1만 자 제한도 있습니다.
> **코드위젯(코드 에디터)** 에만 넣어 주세요. 무료 요금제는 스크립트가 지워지므로 유료 요금제가 필요합니다.

## 준비 — 게시판 하나 만들기

1. 아임웹 관리자 → **게시판 추가**. 이름은 「청명 일정」처럼 아무거나.
   - **갤러리형**으로 만들면 목록에 사진 썸네일이 함께 나와 보기 좋습니다(선택).
   - 직원만 쓰는 게시판이면 **글쓰기·읽기 권한을 회원(직원)으로** 잠그세요.
2. 그 게시판 목록 주소를 확인합니다. 예: `https://내사이트.com/schedule`
   → 위젯 설정에 넣을 값은 `/schedule` (도메인 뒤부터)
3. 달력을 넣을 페이지(직원만 아는 숨긴 페이지)에 **코드위젯**을 놓고
   `아임웹-일정달력-복사용.txt` 내용을 통째로 붙여넣습니다.
4. 붙여넣은 코드 위쪽 `<section ...>` 줄에서 값을 고칩니다.
   - `data-board="/board"` → **꼭 사장님 게시판 주소로 바꾸세요** (이것만 틀리면 달력이 빕니다)
   - `data-pin="8282"` → 직원 접속 번호
   - `data-write=""` → 글쓰기 주소(예: `/schedule?mode=write`). 비우면 게시판 목록으로 갑니다
   - `data-pages="3"` → 목록을 몇 페이지까지 읽을지 (일정이 많으면 늘리세요)
   - `data-works` / `data-owners` → 작업항목·담당자 목록

## 일정 등록하는 법

위젯 아래 **「일정 등록하기」**를 펼치고 날짜·시간·작업항목(여러 개 선택 가능)·현장명·담당자·
장소·진행상태를 채우면, 게시판에 넣을 **제목**과 **본문**이 자동으로 만들어집니다.

1. **제목 복사** → **③ 게시판 글쓰기 열기** → 제목 칸에 붙여넣기
2. **본문 복사** → 본문 칸에 붙여넣기
3. 본문의 `[BEFORE]` `[AFTER]` 자리에 **사진을 올립니다** (게시판 기본 사진 첨부 기능)
4. 저장 → 달력에서 **새로 고침**을 누르면 그 날짜에 나타납니다

제목은 이런 한 줄이 됩니다. 위젯은 이 줄을 읽어 달력에 뿌립니다.

```
2026-08-14 09:00 | 옥상방수, 누수탐지 | 카카오프렌즈 지곡점 | 송경훈 | 수원 권선구 서호동로26번길 19 | 예정
```

- 칸 순서는 **날짜 시간 | 작업항목 | 현장명 | 담당자 | 장소 | 진행상태** 로 고정입니다
- 작업항목은 쉼표로 여러 개 (중복 선택)
- 없는 칸은 `-` 로 둡니다. 시간은 빼도 됩니다(그날 종일 일정으로 봅니다)
- 제목 뒤에 다른 말이 붙어도(NEW 배지 등) 읽는 데 문제 없습니다

**진행사항을 수정할 때**는 달력에서 일정을 찾아 **「게시글 보기 · 진행사항 수정」**을 누르고
게시판 글 수정으로 본문 `[진행사항]` 아래에 날짜와 함께 덧붙이면 됩니다.

## 보는 법

- **월간** — 한 달 그리드. 각 날짜에 일정 칩이 뜨고 오늘은 노란색, 고른 날은 파란 테두리
- **주간** — 이번 주 7일을 줄로 펼침. 휴대폰에서 글자가 커서 읽기 편합니다
- 날짜를 누르면 아래에 **그날 일정 카드**(시간 · 작업항목 · 담당자 · 장소 · 진행상태)
- 카드의 **BEFORE / AFTER 사진 보기** — 그 게시글을 읽어 사진을 가져옵니다.
  본문에 `BEFORE` `AFTER` 글자가 있으면 그 아래 사진들을 각각 묶어 보여 줍니다
- 작업항목 색은 `data-works`에 적은 **앞에서부터 6개**까지 자동으로 다르게 칠합니다

## 안 될 때

위젯이 상태 줄에 무엇이 문제인지 적어 줍니다.

| 상태 줄 | 뜻과 해결 |
| --- | --- |
| `일정 N개를 읽었습니다` | 정상입니다 |
| `게시판을 읽지 못했습니다 (404)` | `data-board` 주소가 틀렸습니다. 도메인 뒤 경로만 넣으세요 |
| `게시판을 읽지 못했습니다 (Failed to fetch)` | 다른 도메인·다른 사이트 주소입니다. **같은 사이트 안**의 주소여야 합니다 |
| `게시판은 열렸지만 규칙에 맞는 일정 글이 없습니다` | 글 제목이 위 규칙 형태인지 확인하세요 |

그밖에 알아 둘 점:

- 게시판을 **회원 전용**으로 잠갔다면, 직원이 **로그인한 상태**에서만 달력이 채워집니다
- 접속 번호는 위젯 화면을 가리는 것뿐입니다. 게시판 자체의 권한은 아임웹 게시판 설정에서 잠그세요
- 아임웹 게시판 목록의 HTML을 읽는 방식이라, 게시판 **스킨을 바꾸면** 확인이 필요합니다
  (제목 링크만 있으면 대부분 그대로 동작합니다)

## 미리 확인하기

```bash
python3 preview.py                 # widget-preview.html 만들기
python3 -m http.server 8020        # 같은 서버에서 열어야 게시판을 읽습니다
# → http://localhost:8020/widget-preview.html
```
