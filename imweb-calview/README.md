# 청명 일정 정리 + 작업현황 폼 (아임웹)

아임웹 **기본 캘린더 아래에 놓는** 위젯입니다. 두 가지를 합니다.

1. 캘린더에서 **누른 날짜의 일정**을 카드로 정리해 보여 줍니다 (기간별 표·엑셀 복사도 있음)
2. 아임웹 **일정 상세 창이 열리면 그 안에 「청명 작업현황」 폼을 끼워 넣습니다.**
   채우고 버튼 한 번이면 제목과 본문(표)이 채워집니다 — 사진만 얹어 저장하면 끝

```
아임웹-일정정리달력-복사용.txt   ← 코드 에디터에 통째로 붙여넣는 파일
widget.html / widget.css / widget.js · onefile.py · preview.py
```

## 자료를 어디서 읽나

`imweb-probe`로 알아낸 아임웹의 통신을 그대로 씁니다.

```
POST /ajax/calendar_data.cm
보냄  board_code, start(YYYY-MM-DD), end(YYYY-MM-DD)
받음  [{ id, title, start, end, className }]
```

`board_code`는 ① 설정값 → ② **아임웹 캘린더가 스스로 보내는 요청을 엿봐서** → ③ 페이지 안에서
찾기, 순서로 얻습니다. 그래서 **캘린더와 같은 페이지에 두면 설정할 것이 없습니다.**

## 날짜는 아임웹 캘린더를 따라갑니다

- 페이지를 열면 주소의 `?d=2026-08-19` 날짜(없으면 오늘)를 봅니다
- **아임웹 캘린더에서 날짜 칸을 누르면** 아래 목록이 그 날짜로 바뀝니다
  (아임웹 달력 칸에 `data-date`가 있어 그것을 읽습니다)
- 카드의 **열기** — 아임웹 캘린더에서 그 일정을 **대신 눌러** 상세 창을 띄웁니다.
  다른 달이면 캘린더의 ‹ › 를 눌러 그 달로 옮긴 뒤 엽니다

## 상세 창의 「청명 작업현황 채우기」

상세 창이 열리면 그 안에 폼이 붙습니다. 작업항목(여러 개)·현장명·장소·담당자·진행상태·
연락처·진행사항을 채우고

- **제목·본문 채우기** — 제목을 «현장명 · 작업항목 · 담당자»로 바꾸고 본문에 표를 넣습니다
- **본문만 채우기** — 제목은 그대로 두고 본문에만 넣습니다(이미 있는 일정을 고칠 때)
- **표 복사** — 자동 입력이 안 되는 편집기일 때 손으로 붙여넣기

본문에 들어가는 것: 작업항목·현장·장소·담당자·연락처·진행상태 **표**, **진행사항** 목록,
**BEFORE**·**AFTER** 자리. 사진은 그 자리에 아임웹 편집기로 올리고 **저장은 아임웹 저장 버튼**으로
합니다(위젯이 몰래 저장하지 않습니다).

## 설정

- `data-works` — 작업항목. 일정 제목에서 이 낱말을 찾아 배지·필터로 쓰고, 폼의 체크박스가 됩니다
- `data-owners` / `data-states` — 폼의 담당자·진행상태 목록
- `data-board-code` — 비워 두세요. 못 찾을 때만 넣습니다

## 알아 둘 점

- **비공식 경로입니다.** 아임웹이 공개한 방법이 아니라 캘린더가 쓰는 통신·화면을 그대로
  따라 합니다. 아임웹이 바꾸면 깨질 수 있습니다(그때 다시 맞추면 됩니다).
- 폼이 붙지 않으면, 상세 창에서 본문 편집기를 찾지 못한 것입니다. 그때는 `imweb-form` 위젯의
  복사 방식을 쓰세요.
- 날짜가 어긋나 보이면 표 아래 **「받은 자료 확인」**을 펼쳐 보세요. 아임웹이 준 값과
  위젯이 읽은 날짜를 나란히 보여 줍니다.
- 직원만 보게 하려면 이 위젯을 올린 페이지를 아임웹에서 **회원 전용**으로 잠그세요.
