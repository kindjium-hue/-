# 청명 일정 달력 (아임웹 캘린더 형식)

아임웹 **기본 캘린더가 쓰는 일정 자료를 그대로 읽어**, 같은 모양의 달력으로 보여 주고
기간별 표로도 정리해 주는 위젯입니다. 아임웹 캘린더와 **항상 같은 내용**이 나옵니다.

```
아임웹-일정정리달력-복사용.txt   ← 코드 에디터에 통째로 붙여넣는 파일
widget.html / widget.css / widget.js · onefile.py · preview.py
```

## 어떻게 읽나

`imweb-probe` 조사 도구로 알아낸 아임웹의 통신을 그대로 씁니다.

```
POST /ajax/calendar_data.cm
보냄  board_code, start(YYYY-MM-DD), end(YYYY-MM-DD)
받음  [{ id, title, start, end, className }]
```

`board_code`는 세 가지 방법으로 얻습니다(순서대로).

1. 설정에 `data-board-code`를 넣었으면 그것
2. **아임웹 캘린더가 스스로 보내는 요청을 엿봐서** 얻기 (같은 페이지에 있을 때)
3. 페이지 안(스크립트)에서 `board_code` 값을 찾기

그래서 보통은 **캘린더와 같은 페이지에 두기만 하면** 아무 설정 없이 동작합니다.

## 무엇이 되나

- **일 / 주 / 월** 보기 — 아임웹 캘린더와 같은 배치(왼쪽에 기간과 ‹ ›, 오른쪽에 일·주·월)
- 날짜를 누르면 그날 일정 카드 — 시간·기간·작업항목 배지·**열기**
- 여러 날에 걸친 일정은 그 날짜들에 모두 표시됩니다
  (종일 일정의 끝날짜가 «다음 날»로 오는 관례를 하루 당겨 맞춥니다)
- 분류 색(`className`)에 따라 칩 색이 달라집니다
- **기간별로 정리해 보기** — 이번 달 / 3개월 / 올해, 검색, 작업항목으로 고르기,
  건수 요약, **표 복사(엑셀용)** (탭으로 구분된 세 칸: 날짜·일정·작업항목)
- 작업항목은 **제목에서 찾아** 배지로 보여 줍니다(`data-works`에 적은 낱말이 제목에 있으면 표시)

## 설정

붙여넣은 코드의 `<section ...>` 줄에서 고칩니다.

- `data-works` — 작업항목 목록. 제목에서 이 낱말을 찾아 배지·필터로 씁니다
- `data-calendar` — 아임웹 캘린더 페이지 주소. 비우면 이 페이지(`열기` 링크에 씁니다)
- `data-board-code` — 비워 두세요. 위 2·3번으로 못 찾을 때만 넣습니다

## 고치는 것은 아임웹에서

일정 카드·표의 **열기**를 누르면 아임웹 캘린더의 그 날짜로 갑니다(`?d=날짜&view_type=month`).
거기서 일정을 고치고 돌아와 **오늘**이나 화살표를 눌러 다시 그리면 반영됩니다.

> **이 위젯에서 직접 고치는 기능은 아직 없습니다.** 저장할 때 아임웹이 어떤 주소로 무엇을
> 보내는지 아직 확인되지 않았습니다. `imweb-probe` 도구를 켠 채로 캘린더에서 일정을
> **추가·수정하고 저장**해 보면 그 주소가 기록되고, 그때 넣을 수 있습니다.

## 알아 둘 점

- **비공식 경로입니다.** 아임웹이 공개한 방법이 아니라, 캘린더가 쓰는 통신을 그대로
  따라 하는 방식입니다. 아임웹이 바꾸면 깨질 수 있습니다(그때 다시 맞추면 됩니다).
- 캘린더가 회원 전용이면 **로그인한 상태**에서만 일정이 채워집니다.
- 직원만 보게 하려면 이 위젯을 올린 페이지를 아임웹에서 **회원 전용**으로 잠그세요.
- 아임웹 캘린더와 같은 페이지에 두면, 캘린더가 받아 온 자료를 그대로 쓰기 때문에
  통신이 한 번 줄고 달을 넘길 때도 자동으로 따라옵니다.

## 미리 확인하기

```bash
python3 preview.py    # widget-preview.html 만들기
python3 onefile.py    # 세 파일을 고친 뒤 붙여넣기 파일을 다시 만들 때
```

미리보기는 `/ajax/calendar_data.cm` 이 없는 곳에서는 일정을 못 받아옵니다
(상태 줄에 그 이유가 나옵니다). 실제 확인은 아임웹 캘린더 페이지에서 하세요.
