# 2026년 보육교직원 보수교육기관 자율관리(자체점검) 종합평가

가천대학교부설평생교육원(메디컬)의 자체점검 종합평가 한글 문서를 보완해 다시 작성한 결과물입니다.
원본 양식(표 구조·글꼴·칸 구성)은 그대로 두고 **구분별 종합평가 칸의 본문만** 새로 채웠습니다.

```
2026년 보수교육기관 자율관리(자체점검) 종합평가.docx  결과물 (권장) — 렌더링 확인 완료
2026년 보수교육기관 자율관리(자체점검) 종합평가.pdf   위 문서를 그대로 출력한 것
2026년 보수교육기관 자율관리(자체점검) 종합평가.hwp   원본 양식을 고친 한글 파일 (아래 주의 참고)
2026년 보수교육 자체점검 결과 보고(발표자료).pptx     발표용 슬라이드 10장 (발표자 노트 포함)
2026년 보수교육 자체점검 결과 보고(발표자료).pdf      발표자료를 그대로 출력한 것
종합평가-원고.md                                      문서에 들어간 최종 원고
tools/content.py                                      칸별 원고 (여기만 고치면 됨)
tools/build_docx.js                                   원고로 docx를 만드는 스크립트
tools/build_pptx.js                                   발표용 슬라이드를 만드는 스크립트
tools/rewrite_hwp.py                                  원본 hwp의 본문 칸을 교체하는 스크립트
tools/cfb.py                                          hwp 컨테이너(OLE 복합 문서) 라이터
```

## 어떤 파일을 쓸까

**docx 를 쓰시면 됩니다.** 한글에서 `파일 → 불러오기`로 열어 `.hwp` 로 저장하면
제출용 한글 문서가 됩니다. 표 구조(3열 8행, 병합 포함)는 원본 양식 그대로입니다.

`.hwp` 는 원본 파일의 본문 칸만 직접 바꾼 것입니다. 처음 만든 판은 한글이 저장해 둔
줄 배치 정보를 그대로 믿고 그리는 바람에 글자가 겹쳐 보였고, 지금 판은 그 정보를
모두 지워 한글이 다시 계산하도록 했습니다. 다만 이 작업 환경에는 한글이 없어
직접 열어 확인하지는 못했으니, 열어 보시고 이상하면 docx 쪽을 쓰시면 됩니다.

## 발표자료 구성

표지 → 점검 개요 → 한눈에 보기 → 강점 → 1~4영역(미흡·개선·기대 효과) → 컨설팅·환류 → 마무리,
모두 10장입니다. 슬라이드마다 발표자 노트를 넣어 두었습니다.

## 제출·발표 전에 채워야 할 곳

`강점 및 우수한 점` 첫 문단과 발표자료 3쪽의 **(1학기 이수 인원 ○○명, 만족도 평균 ○○점)** 은
실제 수치로 바꿔 주세요. 지어내지 않으려고 자리만 남겨 두었습니다.

## 무엇을 고쳤나

- **오탈자·표현** : `학습지들` → `학습자들`, `좋았읍니다` → `좋았습니다`, 문장 종결과 존대 통일,
  불릿 기호를 `*` 에서 `○` 로 통일.
- **미흡 및 개선점 칸의 구조** : 개선 계획만 적혀 있어 '미흡'이 드러나지 않던 것을
  영역마다 `[미흡사항]` → `[개선계획]` 순서로 나누고, 추진 시기를 함께 적었습니다.
- **교육과정 근거 정정** : "2024년 개정 표준보육과정" → **제4차 어린이집 표준보육과정**과
  **2019 개정 누리과정**, 그리고 매년 개정되는 **보육사업안내**로 바로잡았습니다.
- **표현 순화** : "아동학대를 중점 지도하여 현장에서 물의를 방지" →
  아동권리 존중과 아동학대 예방(신고의무자 교육 포함) 필수 모듈 편성으로 다시 썼습니다.
- **빈칸 보완** : 비어 있던 `컨설팅` 칸에 미진행 사유와 2학기 신청 계획을 적고,
  `결과활용 방안 및 차후 환류사항` 을 점검 → 개선계획 → 공유 → 재점검의 환류 구조로 확장했습니다.

## 원고를 다시 고칠 때

`tools/content.py` 의 문구만 수정한 뒤 아래를 실행합니다.

```bash
# 발표자료
npm install pptxgenjs
node tools/build_pptx.js "2026년 보수교육 자체점검 결과 보고(발표자료).pptx"

# Word 문서 (권장)
npm install docx
python3 -c "import sys,json; sys.path.insert(0,'tools'); from content import CELLS; \
  k={50:'강점',86:'영역1',96:'영역2',106:'영역3',124:'영역4',139:'컨설팅',149:'환류'}; \
  json.dump({k[a]:b for a,b in CELLS.items()}, open('content.json','w'), ensure_ascii=False)"
node tools/build_docx.js content.json "2026년 보수교육기관 자율관리(자체점검) 종합평가.docx"

# 한글 파일
pip install olefile
python3 tools/rewrite_hwp.py <원본.hwp> "2026년 보수교육기관 자율관리(자체점검) 종합평가.hwp"
```

원본 파일의 표 구조에 맞춰 칸 번호가 정해져 있으므로, 양식이 바뀌면
`tools/content.py` 의 칸 번호(LIST_HEADER 레코드 인덱스)도 함께 맞춰야 합니다.
