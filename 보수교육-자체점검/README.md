# 2026년 보육교직원 보수교육기관 자율관리(자체점검) 종합평가

가천대학교부설평생교육원(메디컬)의 자체점검 종합평가 한글 문서를 보완해 다시 작성한 결과물입니다.
원본 양식(표 구조·글꼴·칸 구성)은 그대로 두고 **구분별 종합평가 칸의 본문만** 새로 채웠습니다.

```
2026년 보수교육기관 자율관리(자체점검) 종합평가.hwp   결과물 (한글 5.0)
종합평가-원고.md                                      한글 파일에 들어간 최종 원고
tools/content.py                                      칸별 원고 (여기만 고치면 됨)
tools/rewrite_hwp.py                                  원본 hwp의 본문 칸을 교체하는 스크립트
tools/cfb.py                                          hwp 컨테이너(OLE 복합 문서) 라이터
```

## 제출 전에 채워야 할 곳

`강점 및 우수한 점` 첫 문단의 **(1학기 이수 인원 ○○명, 만족도 평균 ○○점)** 은
실제 수치로 바꿔 주세요. 지어내지 않으려고 자리만 남겨 두었습니다.

## 무엇을 고쳤나

- **오탈자·표현** : `학습지들` → `학습자들`, `좋았읍니다` → `좋았습니다`, 문장 종결과 존대 통일,
  불릿 기호를 `*` 에서 `○` 로 통일.
- **미흡 및 개선점 칸의 구조** : 개선 계획만 적혀 있어 '미흡'이 드러나지 않던 것을
  영역마다 `[미흡사항]` → `[개선계획]` 순서로 나누고, 추진 시기를 함께 적었습니다.
- **교육과정 근거 정정** : "2024년 개정 표준보육과정" → **제4차 어린이집 표준보육과정**과
  **2019 개정 누리과정**, 그리고 매년 개정되는 **보육사업안내**로 바로잡았습니다.
- **표현 순화** : "아동학대를 중점 지도하여 현장에서 물의를 방지" →
  아동권리 존중과 아동학대 예방(신고의무자 교육 포함) 필수 모듈 편성으로 다시 썼습니다.
- **빈칸 보완** : 비어 있던 `컨설팅` 칸에 미진행 사유와 2학기 신청 계획을 적고,
  `결과활용 방안 및 차후 환류사항` 을 점검 → 개선계획 → 공유 → 재점검의 환류 구조로 확장했습니다.

## 원고를 다시 고칠 때

`tools/content.py` 의 문구만 수정한 뒤 아래를 실행하면 한글 파일이 다시 만들어집니다.

```bash
pip install olefile
python3 tools/rewrite_hwp.py <원본.hwp> "2026년 보수교육기관 자율관리(자체점검) 종합평가.hwp"
```

원본 파일의 표 구조에 맞춰 칸 번호가 정해져 있으므로, 양식이 바뀌면
`tools/content.py` 의 칸 번호(LIST_HEADER 레코드 인덱스)도 함께 맞춰야 합니다.
