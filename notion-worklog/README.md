# 현장 작업 현황 → 노션

현장 업무의 **일정·진행상태·사진·견적서**를 휴대폰 웹 폼에서 올리면
노션 데이터베이스에 한 줄씩 쌓이는 작은 서버입니다.
**작업항목을 고르고 고객명·평수만 넣으면 회사 견적서 양식 그대로 PDF도 만들어 줍니다.**
(청명옥상방수 · 청명종합설비 · 뚜뚜베관케어 세 사업자 양식을 모두 다룹니다.)

- 직원은 **노션 계정이 없어도** 됩니다. 링크 하나만 열면 끝.
- 사진은 여러 장 한꺼번에, 브라우저에서 자동으로 크기를 줄여 올립니다.
- 견적서(PDF·엑셀·한글)는 노션 행의 `견적서` 파일 속성에 바로 첨부됩니다.
- 이미 등록한 업무는 목록에서 눌러 **진행상태 + 진행 사진 + AFTER 사진**을 추가할 수 있습니다.
- 시공 전후 사진은 `BEFORE` / `AFTER` 칸으로 나눠 올립니다.
- 서버 없이 **노션 데이터베이스만 먼저** 만들어 쓰셔도 됩니다 (1~4단계, 설치 필요 없음).

```
등록 폼(/)  →  작업항목 고르고 (평수 넣으면 견적서 자동 생성)
            →  노션 DB에 새 행 + 사진 / 견적서 / BEFORE·AFTER 첨부
목록(/entries)  →  업무 선택  →  상태 변경 + 진행 메모 + AFTER 사진
견적서(/quote)  →  작업항목 + 고객명 + 평수  →  견적서 PDF 바로 내려받기
```

| 폼 입력칸 | 노션 속성 | 형식 |
|---|---|---|
| 현장명 | `현장명` | 제목 |
| 작업항목 | `작업항목` | 선택 (누수탐지·누수피해복구·하수구막힘·옥상방수·외벽방수·기타) |
| 진행상태 | `진행상태` | 선택 (접수·견적·예정·진행중·완료·보류) |
| 작업 시작일 / 종료일 | `작업일` | 날짜(기간) |
| 담당자 | `담당자` | 선택 (새 이름은 자동 추가) |
| 현장 주소 | `주소` | 텍스트 |
| 연락처 | `연락처` | 전화번호 |
| 평수 | `평수` | 숫자 (평) |
| 견적서·문서 | `견적서` | 파일 (자동 생성분 + 직접 첨부분) |
| BEFORE 사진 | `BEFORE` | 파일 (시공 전) |
| AFTER 사진 | `AFTER` | 파일 (시공 후) |
| 메모 / 현장 사진 | 페이지 본문 | 문단 + 이미지 블록 |

`견적금액` 속성은 두지 않습니다. 금액은 자동 생성된 견적서 PDF에 찍힙니다.
표에서 금액도 보고 싶으시면 `견적금액` 숫자 속성을 만들어 두면 폼이 알아서 채웁니다.

## 1단계 — 노션 토큰 만들기 (5분)

1. <https://www.notion.so/my-integrations> 접속 → **New integration**
2. 이름은 `현장 업무 폼` 정도로, 워크스페이스를 고르고 저장
3. **Internal Integration Secret**을 **Show → Copy** (`ntn_`으로 시작하는 문자열)

> 이 토큰은 워크스페이스에 글을 쓸 수 있는 열쇠입니다. 카톡·메일로 돌리지 말고
> `.env` 파일에만 두세요. `.env`는 git에 올라가지 않습니다.

## 2단계 — 노션 페이지를 integration에 연결

1. 노션에서 업무 기록을 담을 페이지를 하나 만듭니다 (예: `현장 관리`)
2. 그 페이지 우측 상단 **···** → **연결** (Connections) → 1단계에서 만든 integration 선택
3. 페이지 URL을 복사합니다 (`https://www.notion.so/...`)

이 단계를 건너뛰면 아래 3단계에서 `404` 오류가 납니다. 노션은 **명시적으로 연결한
페이지만** integration에 보여 줍니다.

## 3단계 — 노션에 데이터베이스 만들기 (설치 필요 없음)

**맥이면 `notion-worklog` 폴더의 `노션DB만들기.command`를 더블클릭하세요.**
터미널 창이 열리면 1단계의 토큰과 2단계의 페이지 URL을 붙여넣으면 끝입니다.
맥에 들어 있는 `python3`만 쓰므로 따로 설치할 것이 없습니다.

> 첫 실행 때 "확인되지 않은 개발자" 경고가 나오면 파일을 **우클릭 → 열기**로 한 번만 열어 주세요.

터미널에서 직접 하거나 맥이 아니라면:

```bash
cd notion-worklog
python3 setup_db.py                                        # 물어보면서 진행
python3 setup_db.py --parent-page "<2단계의 페이지 URL>"     # 한 줄로
```

속성이 모두 갖춰진 `현장 업무` 데이터베이스가 만들어지고, 토큰과 DB ID를 `.env`에
저장할지 물어봅니다(나중에 휴대폰 폼을 켤 때 필요합니다).

이미 쓰고 있는 DB에 빠진 속성만 채워 넣을 수도 있습니다.

```bash
python3 setup_db.py --database "<기존 DB URL>"
```

## 4단계 — 노션에서 뷰와 공유 설정 (손으로)

뷰는 노션 API로 만들 수 없어서 이것만 앱에서 직접 하시면 됩니다.
[노션에서 보기 좋게 만들기](#노션에서-보기-좋게-만들기)를 보세요. 여기까지만 해도
노션 앱에서 업무를 적고 사진·견적서를 올리며 팀과 공유할 수 있습니다.

## 5단계 (선택) — 휴대폰 웹 폼 서버 켜기

사진·견적서를 자동으로 올리고 견적서를 자동 생성하려면 서버를 띄웁니다.

```bash
cd notion-worklog
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

브라우저에서 <http://localhost:8000> 을 열어 폼이 뜨는지 확인합니다.
(3단계에서 `.env` 저장을 건너뛰었다면 `cp .env.example .env` 후 값을 채워 주세요.)

### 휴대폰에서 열기

| 상황 | 방법 |
|---|---|
| 사무실 와이파이 안에서만 쓴다 | 같은 와이파이에서 `http://<PC IP>:8000` (예: `http://192.168.0.12:8000`) |
| 현장(LTE)에서도 써야 한다 | `cloudflared tunnel --url http://localhost:8000` → 출력된 `https://…trycloudflare.com` 주소를 카톡으로 공유 |
| 항상 켜 두고 쓴다 | Render·Railway·Fly 등에 올리고 시작 명령을 `uvicorn app:app --host 0.0.0.0 --port $PORT` 로, `.env` 값은 대시보드의 환경변수로 등록 |

휴대폰 사파리/크롬에서 **홈 화면에 추가**해 두면 앱처럼 한 번에 열립니다.
카메라 접근과 `공유하기` 버튼은 `https`에서만 동작하므로 현장용은 터널이나 배포를 쓰세요.

### 아무나 열지 못하게 하기

`.env`에 `WORKLOG_ACCESS_CODE=8282` 처럼 코드를 넣으면 첫 방문 때 코드를 묻고,
한 번 입력하면 30일간 유지됩니다. 직원에게는 링크와 코드를 함께 알려 주면 됩니다.

## 견적서 자동 생성

실제 견적서 PDF에서 좌표·색·표 구조·도장을 그대로 떠 왔습니다. **바뀌는 값은 작업항목·고객명·평수**뿐이고,
평수에 비례하는 항목과 고정 항목(폐기물처리·보양•청소 등)이 자동으로 계산됩니다.
작업항목은 견적서 표 왼쪽 `공사명` 칸에 찍히고, **작업항목에 따라 사업자 정보(브랜드)가 바뀝니다.**

| 작업항목 | 견적서에 찍히는 사업자 | 단가 |
|---|---|---|
| 옥상방수 | 청명옥상방수 (254-11-02805) | 등록됨 — 평당 110,000 + 고정 400,000 |
| 외벽방수 | 청명종합설비 (552-08-01511) | 등록됨 — 평당 55,000 + 고정 1,100,000 |
| 누수탐지 · 누수피해복구 · 하수구막힘 | 뚜뚜베관케어 (배관 및 냉.난방 공사업) | 미등록 |
| 기타 | 청명종합설비 | 미등록 |

**단가는 평당**입니다. 51평 옥상방수 → 합계 6,010,000원(실제 견적서와 동일).
㎡가 아니라 평이며, 폼에서는 입력한 평수의 ㎡ 환산값을 옆에 같이 보여 줍니다.

세 가지 방법으로 만들 수 있습니다.

1. **등록 폼의 `견적서 자동 생성` 칸** — 작업항목을 고르고 평수를 넣어 제출하면
   견적서 PDF를 만들어 노션 행의 `견적서`에 첨부합니다.
2. **`/quote` 화면** — 작업항목 + 고객명 + 평수만 넣으면 PDF가 바로 내려옵니다.
   노션 설정이 없어도 되고, 휴대폰에서는 그대로 카톡으로 전달할 수 있습니다.
3. **명령줄**

```bash
python quote.py --고객 "카카오프렌즈 지곡점" --평수 51 --항목 옥상방수
python quote.py --고객 "탑동 881~8" --평수 10 --항목 외벽방수 --금액 1400000
python quote.py --고객 "매탄동 현대아파트" --평수 30 --항목 옥상방수 --할인 15   # 15% 깎고 만원 단위 내림
```

### 단가·문구 바꾸기

전부 `quote_config.json` 한 파일에 있습니다. 서버를 다시 시작하지 않아도 다음 견적서에 반영됩니다.
단가는 **작업항목별로** 둡니다.

```json
{ "브랜드": {
    "청명옥상방수": { "상호명": "청명옥상방수", "등록번호": "254-11-02805", "…": "…" }
  },
  "작업항목": {
    "옥상방수": {
      "브랜드": "청명옥상방수",
      "공사명": "옥상\n바닥 방수",
      "품목": [{ "품목": "바탕면작업", "단가": 20000, "수량": "평수" },
               { "품목": "폐기물처리", "단가": 200000, "수량": 1 }],
      "특이사항": ["* 공사명: 옥상 방수 공사", "…"]
    },
    "누수탐지": { "브랜드": "뚜뚜베관케어", "품목": [], "특이사항": [] }
} }
```

- `"수량": "평수"` → 입력한 평수를 수량으로 씀 (평당 단가 항목)
- `"수량": 1` → 평수와 무관한 고정 1식
- `"브랜드"` → 견적서 상단 사업자 정보를 고릅니다 (청명옥상방수 / 청명종합설비 / 뚜뚜베관케어)
- `"공사명"` → 표 왼쪽에 찍히는 이름. `\n`을 넣으면 원본처럼 여러 줄로 나옵니다
- 항목별 `특이사항`·`담당`·`연락처`가 비어 있으면 파일 맨 아래 공통값을 씁니다

**지금은 옥상방수·외벽방수 단가만 들어 있습니다.** 누수탐지·누수피해복구·하수구막힘은
단가를 넣기 전까지 견적서를 만들지 않고 "단가 미등록"으로 안내합니다.
등록 자체는 정상으로 되니, 단가를 알려 주시면 넣어 드리겠습니다.

### 알아 둘 점

- **최종 네고 금액은 기본값이 합계와 같습니다.** 깎아 줄 금액은 매번 판단이 필요하니
  `--금액` / `--할인`, 또는 폼의 `최종 네고 금액` 칸으로 넣어 주세요.
- 원본 견적서는 `합계 금액(부가세별도)`가 1,200,000, `최종 네고 금액`이 1,400,000으로
  서로 달랐습니다(예전 초안이 남은 것으로 보입니다). 자동 생성분은 **둘을 최종 청구액으로 맞춥니다.**
- 대표자 도장은 원본 견적서에서 뽑아 `assets/seal.png`로 넣어 두었고, 자동으로 같은 자리에 찍힙니다.
  (옥상방수·외벽방수 견적서의 도장이 동일한 것을 확인했습니다.)
  찍지 않으려면 `quote_config.json`의 `"도장"` 값을 비우세요.
- 한글 폰트가 필요합니다. 우분투/데비안은 `sudo apt-get install fonts-nanum`,
  그 밖에는 `QUOTE_FONT=/폰트/경로.ttf` 환경변수로 지정하면 됩니다.
  (윈도우·맥은 기본 폰트를 자동으로 찾습니다.)

## 노션에서 보기 좋게 만들기

`setup_db.py`는 표 하나만 만듭니다. 노션에서 뷰를 추가하면 훨씬 쓰기 편해집니다.

- **보드 뷰**: 그룹 기준 `진행상태` → 접수/진행중/완료 칸반으로 한눈에
- **캘린더 뷰**: 날짜 기준 `작업일` → 이번 주 현장 일정
- **갤러리 뷰**: 카드 미리보기를 **BEFORE**로 두면 시공 전 사진이 카드 표지로 뜹니다
  (본문에 넣은 사진을 쓰려면 `페이지 콘텐츠`)
- **공유**: DB 페이지 우측 상단 `공유`에서 팀원을 초대하거나, `웹에 게시`로 열람 전용
  링크를 만들어 거래처에 보낼 수 있습니다

## 알아 둘 점

- **노션 무료 플랜은 파일 하나당 5MB**까지만 올라갑니다. 유료 플랜은 5GB.
  사진은 브라우저에서 긴 변 2000px·JPEG로 줄여 보내므로 보통 1MB 밑으로 떨어지지만,
  견적서 PDF가 5MB를 넘으면 노션이 거부합니다(폼에 안내 문구가 뜹니다).
- 아이폰 HEIC 사진은 브라우저가 JPEG로 바꿔 올립니다. 자바스크립트가 막힌 환경이라면
  `requirements.txt`의 `pillow-heif` 주석을 풀어 서버에서 변환하세요.
- 속성 이름을 바꾸고 싶으면 `app.py` 위쪽의 `FIELD_*` 상수와 `notion_lite.py`의 `SCHEMA`를
  같이 고치면 됩니다. DB에 없는 속성은 자동으로 건너뛰므로 일부만 써도 동작합니다.
- 사진 크기·용량 상한은 `.env`의 `WORKLOG_MAX_IMAGE_PX`, `WORKLOG_MAX_UPLOAD_MB`로 조정합니다.

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| `설정 필요` 화면이 뜬다 | `.env`의 `NOTION_TOKEN` 또는 `NOTION_DATABASE_ID`가 비어 있음 |
| `401` / `404` | 토큰이 틀렸거나, 2단계의 **연결**을 안 했음 |
| 사진이 첨부되지 않음 | 파일 하나가 5MB를 넘었을 수 있음(무료 플랜) |
| 담당자 목록이 안 늘어난다 | 등록 후 5분 뒤 갱신됩니다(스키마 캐시). 서버를 다시 시작하면 즉시 반영 |
| `한글 폰트를 찾지 못했습니다` | `sudo apt-get install fonts-nanum` 또는 `QUOTE_FONT`로 폰트 지정 |

노션 API를 대신하는 가짜 서버로 DB 생성·등록·업로드·견적서·진행 업데이트 흐름을 검사합니다.

```bash
python3 -m unittest test_app -v
```

## 파일 구성

```
노션DB만들기.command  맥에서 더블클릭하면 노션 DB를 만들어 주는 실행 파일
setup_db.py        노션 DB 생성·속성 보정 (설치 없이 python3만으로 동작)
notion_lite.py     표준 라이브러리만 쓰는 최소 노션 도구 + DB 속성 정의
app.py             FastAPI 서버 (화면 + 업로드 처리)
notion_api.py      노션 API 래퍼 (파일 업로드 3단계, 페이지/블록/DB)
quote.py           견적서 PDF 생성기 (양식 좌표 + 금액 계산 + CLI)
quote_config.json  회사 정보·품목 단가·특이사항 (여기만 고치면 됨)
assets/seal.png    대표자 도장 (원본 견적서에서 추출)
templates/         폼·목록·진행 업데이트·견적서 화면
static/            모바일 CSS, 사진 축소·업로드 스크립트
test_app.py        가짜 노션으로 돌리는 통합 테스트 (44개)
```
