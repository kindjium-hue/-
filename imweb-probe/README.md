# 아임웹 캘린더 조사 도구

아임웹 **기본 일정(캘린더) 위젯**의 화면 구조와, 일정을 추가·수정할 때 오가는 통신을
정리해 보여 주는 **임시** 위젯입니다. 캘린더의 내용을 읽어 정리하거나 고치는 위젯을
만들려면, 아임웹이 어떤 주소로 무엇을 주고받는지 먼저 알아야 해서 만든 도구입니다.

```
아임웹-조사도구-복사용.txt   ← 코드 에디터에 통째로 붙여넣는 파일
widget.html / widget.css / widget.js · onefile.py · preview.py
```

## 쓰는 법

1. 이 위젯을 **캘린더와 같은 페이지**에 코드위젯으로 올리고 저장합니다
2. 페이지를 새로 고칩니다 (**관리자로 로그인한 상태**여야 합니다)
3. 캘린더에서 **시험용 일정 하나를 추가**하고, 이어서 **수정**도 해 봅니다
4. **결과 복사**를 눌러 그 내용을 알려 주세요
5. 확인이 끝나면 **이 위젯은 지우세요** (평소에 켜 둘 도구가 아닙니다)

## 무엇을 알려 주나

```
[화면 구조]
· div#calendar_widget.cal_wrap.calendar-month — 자식 2개, 글자 39자
· 쓰이는 data 이름: data-date, data-idx
  - span.sched_title = 옥상방수 · 카카오프렌즈 지곡점

[통신 기록]
1) GET /api/widget/calendar/list?site=1&year=2026&month=8&token=(가림:40자)
   받음: 200 · { code, list: 목록 2개 → { idx, date, title, category_idx, content } }
2) POST /api/widget/calendar/save
   보냄: 묶음: idx(1자), date(10자), title(5자), category_idx(1자), content(9자), all_day(1자)
```

이 정도면 **읽는 위젯**은 확실히 만들 수 있고, **고치는 위젯**도 가능한지 판단할 수 있습니다.

## 무엇을 수집하지 않나

- **쿠키·비밀번호·인증 토큰**은 기록하지 않습니다
- 주고받은 **실제 값**은 적지 않습니다. 항목 이름과 값의 **길이**만 적습니다
- 주소의 값 중 `token`·`key`·`csrf`류이거나 40자를 넘는 것은 `(가림:40자)`로 바꿉니다
- 그래도 결과에 전화번호·주소 같은 것이 보이면 **지우고** 보내 주세요

## 설정

- `data-filter` — 관심 있는 주소 조각 (기본 `calendar,schedule,event,widget`).
  기록이 하나도 안 잡히면 **비워서** 모든 통신을 보게 하세요.

## 알아 둘 점

- 이 도구는 사이트가 스스로 부르는 통신을 **엿보기만** 합니다. 아무것도 바꾸지 않습니다.
- 캘린더가 통신 없이 **서버가 만들어 준 HTML만으로** 그려지는 경우도 있습니다.
  그때는 통신 기록이 비고 «화면 구조»만 나옵니다 — 그것도 유용한 답입니다
  (그 경우 읽기는 화면에서 긁어오고, 고치기는 어렵다는 뜻입니다).
- 아임웹이 공개하지 않은 통신을 쓰는 것은 **비공식 방법**입니다. 아임웹이 업데이트하면
  깨질 수 있고, 그때는 다시 맞춰야 합니다.
