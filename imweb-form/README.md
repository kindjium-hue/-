# 청명 작업현황 작성 폼 (아임웹)

아임웹 **일정(캘린더) 위젯의 「상세 일정」에 붙여넣을 제목과 상세 내용을 만들어 주는** 폼입니다.
작업항목을 고르고 칸을 채우면, 표 형태로 정리된 작업현황이 만들어집니다.

```
아임웹-작업현황폼-복사용.txt   ← 코드 에디터에 통째로 붙여넣는 파일
한번에붙여넣기.html            내용 같음 (브라우저로 열면 바로 확인 가능)

widget.html / widget.css / widget.js   원본 세 파일
onefile.py · preview.py                다시 만들기 · 미리보기
```

## 왜 이렇게 하나

아임웹 일정의 상세 편집기는 **빈 편집기**라서 매번 무엇을 적을지 사람이 기억해야 합니다.
이 폼은 정해진 칸을 채우게 하고, 편집기 도구막대의 **`</>` (HTML 편집)** 버튼으로 넣을 수 있는
표를 만들어 줍니다. 기록이 늘 같은 모양으로 남고, 빠뜨리는 항목이 없습니다.

## 쓰는 법

1. 폼을 채웁니다 — 작업일·시간, **작업항목(여러 개)**, 현장명, 장소, 담당자, 진행상태,
   연락처, 견적·금액, 진행사항(한 줄에 하나), 특이사항
2. 아임웹 달력에서 작업일을 눌러 **상세 일정**을 엽니다
3. **① 제목 복사** → 제목 칸에 붙여넣기
4. **② HTML 복사** → 본문 도구막대의 **`</>`** 를 누르고 붙여넣은 뒤 다시 `</>` 로 돌아오기
5. 본문의 **BEFORE**·**AFTER** 자리에 사진을 넣고 **저장**

`</>` 붙여넣기가 막히는 편집기라면 **③ 글자만 복사**를 쓰세요(표 없이 줄글로 들어갑니다).
화면 아래 **미리보기**에 실제로 들어갈 모습이 그대로 보입니다.

## 제목 형식

기본은 달력 칸에서 읽기 좋은 짧은 형태입니다.

```
09:00 카카오프렌즈 지곡점 · 누수탐지·옥상방수 · 송경훈
```

`달력 위젯용 형식으로`를 켜면 `imweb-schedule` 위젯이 읽는 형태로 바뀝니다.

```
2026-08-14 09:00 | 누수탐지, 옥상방수 | 카카오프렌즈 지곡점 | 송경훈 | 수원시 권선구 … | 예정
```

- 아임웹 자체 캘린더를 쓴다면 **기본 형식**이 보기 좋습니다
- `imweb-schedule` 달력(게시판을 읽는 방식)도 함께 쓴다면 **달력 위젯용 형식**을 켜세요

## 설정

붙여넣은 코드의 `<section ...>` 줄에서 고칩니다.

- `data-works` — 작업항목 (쉼표로 구분)
- `data-owners` — 담당자 (쉼표로 구분)
- `data-states` — 진행상태 (쉼표로 구분)
- `data-calendar` — 일정 달력 페이지 주소. 넣으면 「일정 달력 열기」 링크가 보입니다

## 알아 둘 점

- **사진은 아임웹 편집기에서 넣습니다.** 이 폼은 사진을 올리지 못합니다(자리만 만들어 줍니다).
- 붙여넣는 표는 **인라인 스타일**로 되어 있어, 아임웹 스킨과 무관하게 같은 모양으로 보입니다.
- 진행사항을 나중에 덧붙일 때는 일정을 다시 열어 `진행사항` 목록에 한 줄 추가하면 됩니다.
- 직원만 쓰게 하려면 이 폼을 올린 페이지를 아임웹에서 **회원 전용**으로 잠그세요.

## 미리 확인하기

```bash
python3 preview.py    # widget-preview.html 을 만들고 브라우저로 엽니다
python3 onefile.py    # 세 파일을 고친 뒤 붙여넣기 파일을 다시 만들 때
```
